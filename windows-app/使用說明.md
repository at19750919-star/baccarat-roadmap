# 玖玖百家樂路單離線版

將 `玖玖路單安裝程式-1.0.9-x64.exe` 複製到另一台 Windows 10／11（64 位元）電腦，雙擊安裝。

第一次開啟要輸入業主給的授權碼，並連上網路確認一次。之後若暫時沒有網路，7 天內仍可使用；超過 7 天沒連上，或授權被停用、到期，畫面會鎖定並顯示「請聯絡業主」。雲端備份另外要有網路。從桌面或開始功能表開啟「玖玖百家樂路單」。

- `8`：儲存，輸入名稱後，JSON 與 PNG 存在「文件／玖玖路單」。
- 雲端備份：設定 → 基本設定 →「儲存時上傳雲端」打勾，按 8 儲存時會同時把 JSON＋PNG 送到業主的 OneDrive。預設關閉；上傳失敗會顯示原因並可按「重試雲端備份」，本機檔案不受影響。
- 目前路單與設定會保存在這台電腦，關閉再開會保留。
- `7` 撤銷、`77` 設定、`99` 新局，其餘按鍵和網頁版相同。
- 連按 3 次 `Enter` 全螢幕；`000` 或 `Alt + F4` 關閉。
- 主畫面不顯示 Windows 標題列。

重建安裝檔：在此資料夾執行 `npm ci`，再執行 `npm run dist`。產物位於 `dist`。
