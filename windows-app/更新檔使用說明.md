# 更新檔使用說明

## 做更新檔（你）
改完網頁版、確認 git 已存好後，在 `windows-app` 資料夾執行一個指令：

    npm run make-update

成品在 `dist-updates\玖玖路單更新-1.0.7-N.jjupdate`（N 每次自動加 1）。把這個檔案傳給客戶即可，通常只有幾十 KB 到幾 MB。

- 更新檔是「相對於 1.0.7 完整安裝檔」的累積差異，客戶只要套最新的一個，不必依序套。
- 注意：主頁面 tv.html 取自 git 最新存檔（HEAD），沒 commit 的 tv.html 改動不會進去；其他檔案（js、css、圖片）取自目前資料夾內容。
- 顯示「沒有任何變更」代表和安裝檔內容一樣，不需要做。

## 客戶套用
1. 把 `.jjupdate` 檔案拖進路單視窗；或按 `Ctrl + U` 選檔。
2. 出現「更新完成：版本 1.0.7-N」，畫面自動重新載入。路單與設定都保留。
3. 若出現「更新檔無效，未套用」，代表檔案被改過、損毀或版本不符，原本的畫面不受影響。

## 一定要重發完整安裝檔的情況
- 改了程式外殼（`main.cjs`、`preload.cjs`、Electron 版本、圖示、安裝程式設定）。
- 要升到新版本（例如 1.0.8）：改 `package.json` 版本，執行 `npm run dist`，會同時建立新版本的基準清單。更新檔只能套用在對應版本的安裝檔上（1.0.7 的更新檔不能套在 1.0.8）。
- 新版完整安裝後，舊的更新會自動失效，不會蓋掉新版。

## 簽章私鑰（很重要）
私鑰在 `百家樂路單\update-signing-key\private.pem`（不在 windows-app 內、不會被打包、已加入 .gitignore）。**請另外備份到安全的地方。** 遺失的話，已安裝 1.0.7 的客戶就再也無法收到更新檔，只能重發完整安裝檔（換新金鑰）。不要把它寄給任何人。
