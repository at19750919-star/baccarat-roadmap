# 雲端收件更新步驟（v18：只收 JSON）

這次更新讓雲端收件「只收路單 JSON，不再要 PNG」。新程式碼完整放在 `backend/程式碼-v18-只收JSON.gs`，整份貼上去取代舊的即可。網址不會變。

## 先決條件（很重要）
發布前，請先把 Apps Script 線上「現在這份」程式碼整份複製給 Claude 比對。本機的新程式碼是用 10-24 的版本加上 10-29 的 v17 快照做的，線上可能還有更新；比對確認一致、或把差異併進去之後，再往下做。

## 一、備份舊程式碼
1. 打開 Apps Script 專案（script.google.com，用平常的 Google 帳號登入）。
2. 左邊「檔案」底下，每個檔案（例如「程式碼.gs」、「road_onedrive」）都點開，全選複製，貼到記事本存成檔案，檔名加上日期，例如 `舊版-程式碼-1119.txt`。
3. 這份備份就是萬一出問題時的退路。

## 二、貼上新程式碼
1. 打開 `backend/程式碼-v18-只收JSON.gs`，全選複製。
2. 在 Apps Script 點「程式碼.gs」，全選舊內容，貼上新內容覆蓋。
3. 新檔案已經把 OneDrive 的部分（原本另一個 `road_onedrive` 檔）合併進來了。如果左邊檔案列表還有 `road_onedrive`，請把它刪除（檔案旁的三個點 → 刪除），避免內容重複。
4. 確認檔案上方 `FOLDER_ID` 那一行是原本線上用的那個資料夾 ID（比對舊備份）。
5. 按上方「儲存」（磁碟圖示）。左邊「服務」、「專案設定」裡的 Script Properties（OneDrive 授權）不要動。

## 三、發布新版本（網址不變）
1. 右上角「部署」→「管理部署作業」。
2. 在現有那一筆（類型：網路應用程式）旁按鉛筆「編輯」。
3. 「版本」下拉選「新版本」，說明可寫「v18 只收 JSON」。
4. 按「部署」。出現授權詢問就照畫面允許（用同一個帳號）。
5. 不要用「新增部署作業」，那樣會產生新網址，電視版就連不上了。

## 四、驗證
1. 用電視版輸入幾局路單，存一次（快捷鍵 8，輸入名稱按確定）。
2. 畫面下方應顯示「已收齊 JSON」，且只下載一個 .json 檔，不會有 PNG。
3. 到雲端收件資料夾（OneDrive「路單收件」）看，新增的子資料夾裡只有一個 .json，沒有 .png。
4. 清盤自動儲存也同樣只有 .json。
5. Windows 版若還送 JSON＋PNG，新程式碼仍然收得下（兩個檔都存），不會壞。

## 五、前端何時上線
前端（tv.html、index.html、road_backup.js、app.js）已改成不送 PNG。線上舊後端會因為沒有 PNG 而拒收，所以請「確認第三步已發布完成、第四步驗證通過」之後，才把前端推到 GitHub Pages。

## 出問題怎麼退回
Apps Script「部署」→「管理部署作業」→編輯 → 版本選舊的那一版 → 部署；或把第一步備份的舊程式碼貼回去再發布一次新版本。
