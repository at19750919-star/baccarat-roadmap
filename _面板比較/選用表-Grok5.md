# 路單設定面板・Grok5 選用表

對應樣式：`_面板比較\設定面板-Grok5.css`（可整份替換 `tv-settings-casino.css`）。HTML 不改，總覽 class 寫進 `#tvSettings` 的覆蓋規則。

## 設計說明

底板維持已定案亮紅 `#a5171a` → `#7a0f12`，外框照對話彈窗，上下再加總覽的金條邊角。操作件改走黑金屬，才不會和紅底黏成一片。按鈕、數字、文字、唯讀、下拉、畫面風格各自一款，框層次、邊角裝飾、形狀都有用到。尺寸與內距不改，面板維持 720×887。

## 為何沒採用其他樣式

雕刻金線、青銅漸層、皮革扶手、淺色香檳、點陣、拉絲、菱格、細直條、放射太陽紋、八角金邊、金錠，前面的比較版已各用過。金牌鉚釘、黃銅銘牌、金屬機台鍵、螺絲與燈泡要額外留白，56px 鍵位放不下。氈布款不可用在彈窗。主色漸層用 `--state-1` → `--state-2`，會和紅底板黏在一起。半透明毛玻璃在實色紅底上會發濁。

不採用資料夾式頁籤，因為那是與面板一體的內容區。不採用數碼管，因為這裡是可編輯輸入。不採用籌碼鈕，因為不是下注面額。不採用卡片式單選，因為畫面風格必須維持單行。不採用分組卡片，因為再加一層底板會冒出垂直捲軸。

## 驗證

`看面板.py` 以本機 Chrome 開 `tv.html`，換上這份 CSS。三個分頁都是 720×887，內容高與可視高都是 645，沒有垂直捲軸，沒有頁面錯誤。非零圓角只有 `50%` 與 `999px`。字型是 Noto Serif TC、Cinzel，以 serif 結尾。

量到的外觀：作用中分頁只有 2px 金色底線、外框線為 none；一般按鈕背景含 L 角金線與斜紋，懸停上移 2px；數字框背景是絨點；可改鍵是透明底加 2px 底線；唯讀鍵是虛線加斜紋；風格未選含鑽石角、選中是金色實心；下拉是虛線邊框；關閉鈕是正圓黑底加外光。色票按鈕背景仍是 `--swatch-color`。
