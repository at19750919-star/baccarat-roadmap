# 選用表：路單設定面板（Codex）

## 選材說明

| 主外觀候選（規範名稱） | 適合或不適合本面板的原因 |
| --- | --- |
| 雕刻金線 | 適合密集設定介面：深色控制底、內縮金線和紅色面板能拉開層次；套在一般按鈕、輸入框與風格選項能維持同一套外觀。 |
| 金牌鉚釘 | 適合數據看板或頂部金條標牌；裝飾和內距會搶過表單內容，也可能改變元件盒模型，不適合作為整個設定面板的主外觀。 |
| 皮革扶手 | 紅色材質和主色相近，但車縫虛線、明顯立體陰影較重，密集表單會顯得繁複，且總覽示範的顏色不跟隨面板紅色變數。 |
| 預設金線 | 作為一般表單主題可用；與雕刻金線相比缺少內框層次，較難在現有紅底上建立控制項的清晰邊界。 |

**選用：雕刻金線為主材質、直角為主形狀；金色漸層實心只用於選中項與唯一主要儲存按鈕。** 開關和滑桿軌道用膠囊，標題列圖示鈕與色票使用正圓。主色保留目前紅色變數。依據規範原句：「先為整頁定一套『主外觀』＝1 種主材質（或 1 組 `.kit` 組合）＋1 種主形狀，頁上大多數按鈕、面板、標籤都用它」；「同一頁總共用的材質不超過 3 種、形狀不超過 2 種」；「同一排、同一組的元件不得混用不同材質或形狀；層級只用『主要／次要／危險』的實心、線框、顏色差異做出來」。

## 角色選用表

| 角色 | 元件結構 | 外觀材質 | 形狀 | 理由 |
| --- | --- | --- | --- | --- |
| 標題列 | 對話彈窗與抽屜 | 雕刻金線 | 直角 | 沿用金線彈窗框；標題以金色襯線字建立焦點。 |
| 圓形圖示鈕 | 圓形圖示按鈕 | 雕刻金線 | 正圓 | 關閉與視窗尺寸切換是標題列操作，正圓便於辨識且兩顆一致。 |
| 分頁 | 底線頁籤 | 雕刻金線 | 直角 | 頁面級分類使用底線標示目前分頁，不把頁籤做成一般按鈕。 |
| 畫面風格單選 | 按鈕式單選 | 雕刻金線；選中為金色漸層實心 | 直角 | 同組未選項統一雕刻金線，以實心選中狀態表示目前選擇。 |
| 數字輸入 | 數字框 | 雕刻金線 | 直角 | 多個數值欄位統一深底金框，保留文字清晰度。 |
| 文字輸入 | 基本輸入框 | 雕刻金線 | 直角 | 路徑與清盤提示欄和其他輸入欄採同一材質。 |
| 唯讀鍵位框 | 唯讀專用明顯樣式 | 雕刻金線 | 直角 | 虛線暗金框和深色斜紋底辨識唯讀狀態，不改盒子尺寸。 |
| 開關 | 勾選、單選與金色開關 | 雕刻金線 | 膠囊 | 軌道膠囊、圓形滑塊；同組開關一致。 |
| 滑桿 | 單軸滑桿 | 雕刻金線 | 膠囊 | 軌道膠囊、滑塊正圓，延續控制項金色焦點。 |
| 下拉選單 | 自訂下拉選單 | 雕刻金線 | 直角 | 觸發鈕與展開清單使用同一金線及直角外形。 |
| 一般按鈕 | 基本按鈕 | 雕刻金線 | 直角 | 全面板一般操作統一深底、金框與內縮線。 |
| 主要儲存 | 基本按鈕 | 金色漸層實心 | 直角 | 唯一主要動作以實心金色提高優先度。 |
| 取消／恢復預設 | 基本按鈕 | 雕刻金線（低干擾線框） | 直角 | 保留操作可見性，以透明底和暗金框降低優先度。 |
| 刪除 | 紅色危險按鈕 | 雕刻金線（危險色線框；二次確認為危險色實心） | 直角 | 以危險色區分刪除，確認狀態提高警示。 |
| 限紅表 | 金頭資料表 | 雕刻金線 | 直角 | 表頭金字及細金分隔線適合密集數值設定。 |
| 小標題 | 金色標籤 | 雕刻金線 | 直角 | 使用金色字與細分隔線，區分分組但不額外加重卡片裝飾。 |
| 狀態訊息 | 右下通知與綠色橫條 | 雕刻金線 | 直角 | 固定狀態以底色與左側金條呈現，不使用裸色文字。 |

角色名稱採規範 4.1 元件結構名稱；原版 CSS 的 `#tvSettings` 覆蓋選擇器只承接同一套結構外觀，不改 HTML 或互動行為。

不採用金牌鉚釘作主外觀，因為其頂部金條與鉚釘會讓密集設定欄位過度裝飾；不採用皮革扶手，因為車縫線和立體層次不適合全頁密集控制項；不採用預設金線，是因為雕刻金線提供一致的內縮金線層次。

## 特殊外觀

唯一特殊外觀為彈窗四角金色角飾，用在整個路單設定對話框外框；不加到一般按鈕、清單或欄位。
