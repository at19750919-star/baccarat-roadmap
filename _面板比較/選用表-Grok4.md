# 路單設定面板・Grok4 選用表

對應樣式：`_面板比較\設定面板-Grok4.css`（可整份替換 `tv-settings-casino.css`）。HTML 不改，總覽 class 寫進 `#tvSettings` 的覆蓋規則。

## 設計說明

面板底鎖定 `#a5171a` → `#7a0f12`，標準尺寸 720×887，三個分頁不加高、不加內距。2026-11-20 已定案：按鈕、輸入框、唯讀固定按鍵用不同元件結構。

| 主外觀候選（規範名稱） | 適合或不適合本面板的原因 |
| --- | --- |
| 雕刻金線＋方形 | 原版與 Codex 已用。已定案取消「按鈕、輸入框都用雕刻金線」。 |
| 青銅漸層＋方形 | Grok、Gemini 已用。 |
| 皮革扶手＋方形 | Codex2 已用。車縫與左右內距塞不進 56px 鍵位。 |
| 淺色香檳＋方形 | Grok3 已用。整頁亮底會壓過唯一的金色儲存。 |
| 組裝式黑底拉絲／菱格／細直條／酒紅立體／古銅斜紋 | Grok2、Gemini2、Gemini3、Gemini4、Gemini5、Gemini6 已各用一組。 |
| 金牌鉚釘、黃銅銘牌、金屬機台鍵 | 鉚釘、螺絲或燈號要額外留白，窄鍵位放不下，也不能鋪滿整頁。 |
| 氈布、主色漸層 | 氈布不可用在彈窗。主色漸層用 `--state-1`→`--state-2`，和紅面板黏在一起。 |
| 半透明毛玻璃、無外框柔光 | 實色紅底上會發濁，或讓密集鍵位失去邊界。Gemini5、Gemini6 已拿來當卡片。 |
| 組裝式：純黑＋點陣＋浮起／凹陷＋單線＋無邊角，再加方形 | 純黑和紅面板分開。點陣是還沒用過的紋理，1px 單線不吃內距。按鈕用浮起，可填欄用凹陷，唯讀欄另用虛線斜紋。56px 鍵位、七顆試聽鈕都不改盒。 |

**選用：一組 `.kit.fill-black.tex-dots.light-raised.frame-single.corner-none` 為主外觀、方形為主形狀。可填欄同一組，光影改 `.light-inset`。金色漸層實心（`.skin-gold`）只給選中的畫面風格與底部唯一「儲存」。** 開關與滑桿軌道用膠囊，頁首圖示鈕、色票、滑塊用正圓（正圓不計入形狀上限）。

依據規範原句：「先為整頁定一套『主外觀』＝1 種主材質（或 1 組 `.kit` 組合）＋1 種主形狀……另外最多再挑 1 種輔助材質。」「同一頁總共用的材質不超過 3 種、形狀不超過 2 種（正圓圖示鈕不計）。」「同一材質用在按鈕與輸入框時，要保留各自結構的差別（按鈕浮起或實心、輸入框凹陷、唯讀欄另有明顯標示）。」「不同網頁要挑不同的主外觀。」「近黑金屬面板是操作區；深綠氈布只給主要內容區與氈布款元件，不可泛用到彈窗。」

特殊外觀只用在 1 處：對話框對角 17px 金角（`.dialog::before`／`::after`）。燈泡、金錠、撲克角標、螺絲、鑽石角、霓虹、緞帶、燕尾都沒用。

不採用資料夾式頁籤，因為那是與面板一體的內容區，不是獨立切換列。不採用數碼管，因為這裡是可編輯輸入。不採用籌碼鈕，因為不是下注面額。不採用卡片式單選，因為畫面風格沒有說明文字、必須維持單行高度。不採用分組卡片，因為再加一層底板會加高並冒出垂直捲軸。

材質 2 種（這一組 kit、金色漸層實心）。形狀 2 種（方形、膠囊；正圓不計）。特殊外觀 1 處。唯讀虛線斜紋、下拉平面漸層、開關與滑桿的深軌金滑塊，是各結構自己的顏色，沒有再加 `.skin-*`。DOM 沒有這些 class，因為 HTML 不能改。

凹陷與浮起只差 `.light-*`，仍是同一組 kit。層級靠實心、線框、危險色，不靠再換材質。
