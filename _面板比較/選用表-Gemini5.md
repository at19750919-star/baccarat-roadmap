# 電視版路單設定面板選用表（Gemini5 總覽原樣複製・功能分明版）

對應樣式檔：`_面板比較\設定面板-Gemini5.css`（可整份替換 `tv-settings-casino.css`）。

---

## 一、設計說明

### 1. 整體想法：回歸總覽原生結構、讓不同功能一眼分清、確保電視遠看清晰

針對上一版（Gemini4）的兩項主要問題——「自創大舞台底板與分隔線」以及「幾乎所有控制項都套用同一套黑底細直條框，導致按鈕、輸入框、唯讀欄、下拉選單不易一眼區分」——本版（Gemini5）在鎖定主色紅底（`--panel: #a5171a` → `--panel-2: #7a0f12`）與標準尺寸（`720×887`）的前提下，完全依《賭場綠金-通用元件規範》第 3.2 節速查表與第 4 節元件目錄重新選型，並嚴格自《賭場綠金-元件總覽.html》原樣複製各元件 CSS（含 hover、active、disabled、focus）：

1. **零自創底板、零自創分隔線**：
   - 取消自創舞台底板，頁籤改採總覽原生的**底線頁籤（`.tabs` / `.tab` / `.tab.active`）**直接坐落於鎖定亮紅面板上；
   - 各設定分組改以總覽**金框小卡（`.mini-card`）**搭配輔助材質**半透明毛玻璃（`.skin-glass`）**呈現，在亮紅底上自然映出沉穩深寶石紅玻璃分組卡片，取代自創暗紅底色；
   - 三分頁小標題統一原樣採用總覽**中間裝飾分隔線（`.div-line-wrap`）**，儲存分頁列間以總覽**虛線分隔線（`.div-dashed`）**輕隔，頁首提示左側以總覽 `.brand-rule` 豎線銜接。
2. **「按的／填文字的／填數字的／唯讀的／選的」五種語意一眼區分**：
   - **可按的按鈕**：採用主材質組裝式 `.kit`（酒紅底 `.fill-wine` ＋ 拉絲 `.tex-brushed` ＋ 立體厚度 `.light-thick` ＋ 單線金框 `.frame-single` ＋ 無角飾 `.corner-none`），視覺明顯**凸起**且具 4px 立體底座與按壓下沉回饋；低干擾操作降為透明**幽靈按鈕（`.tool-btn.ghost`）**；唯一最終送出「儲存」採**金色漸層實心（`.tool-btn.active` / `.skin-gold`）**；刪除採**紅色危險按鈕（`.tool-btn.danger` / `.danger-solid`）**。
   - **可填文字的輸入框**：原樣採用總覽**基本輸入框（`.field`）**，極深黑紅內凹槽（`inset 0 2px 8px #0007`）、左對齊象牙白 `--serif` 襯線字與淡金提示字。
   - **可填數字的數字框**：原樣採用總覽**數字框（`.numbox`）**，深凹槽配置中／右對齊 **22px 粗體 `--disp` 亮金空心 `0` 展示數字**（不小於正式版 22px，確保電視遠距離清晰好讀）。
   - **唯讀（固定按鍵）欄**：原樣採用總覽**唯讀專用明顯樣式（`.field-readonly-distinct`）**——暗金虛線框、45° 暗金斜紋、近黑平底（無內凹陰影）與柔和暗金字（無 Emoji），在「按鍵設定」一眼與可編輯鍵位框區隔。
   - **可選的下拉選單與畫面風格單選**：限紅版本採用總覽**自訂下拉選單（`.picker-btn` / `.picker-list` / `.picker-item`）**，採平面酒紅黑漸層無立體底座、左對齊文字配右側 `▾`；畫面風格採用總覽**按鈕式單選（`.rbtn-group` / `.rbtn-item`）**，未選為平面暗底沉靜選項、選中為金色漸層實心。
3. **電視可讀性提升**：
   - 路單尺寸、桌號、靴號、限紅 16 格、可編輯數字按鍵、延遲秒數等全數數字欄皆維持 **22px**（`Cinzel` 空心 `0`）；標籤文字 16.5～18px、小標題 19px、分頁 18px、按鈕 16～18px，同時確保三個分頁完全無垂直／水平捲軸與零文字裁切。

### 2. 主外觀定案（規範 4.0 / 4.0.1 / 4.0.2 名稱）

- **主外觀（材質 1）**：組裝式 `.kit`（酒紅底 `.fill-wine` ＋ 拉絲 `.tex-brushed` ＋ 立體厚度 `.light-thick` ＋ 單線 `.frame-single` ＋ 無邊角 `.corner-none`）——用於一般動作按鈕與頁首圓鈕
- **輔助材質（材質 2）**：半透明毛玻璃（`.skin-glass`）——用於各分區金框小卡（`.mini-card`）
- **強調材質（材質 3）**：金色漸層實心（`.skin-gold`）——僅用於底部唯一主要送出鈕「儲存」與已選中之「畫面風格」單選按鈕
- **主形狀（形狀 1）**：方形（`.shape-square`，`border-radius: 0`）
- **輔助形狀（形狀 2）**：膠囊（`.shape-pill`，`border-radius: 999px`，僅用於開關軌道與滑桿軌道）
- **正圓（不計入形狀上限）**：圓形（`.shape-circle`，`border-radius: 50%` 且寬高相等，僅用於頁首兩顆圖示鈕、色票與開關／滑桿滑塊）

### 3. 候選主外觀比較與取捨原因

為避開先前各比較版已用過的「雕刻金線」「青銅漸層」「皮革扶手」「黑底拉絲（單線高光）」「深紅菱格（雙色高光）」「黑底細直條（漸層厚框）」，本次評估以下候選：

| 候選主外觀（規範名稱） | 評估與採用／排除原因 |
| --- | --- |
| **組裝式 `.kit`（酒紅 `.fill-wine` ＋ 拉絲 `.tex-brushed` ＋ 立體厚度 `.light-thick` ＋ 單線 `.frame-single` ＋ 無角飾 `.corner-none`）＋ 輔助材質「半透明毛玻璃（`.skin-glass`）」＋ 方形** | **採用**。半透明毛玻璃疊於鎖定亮紅底（`#a5171a→#7a0f12`）上形成深寶石紅卡片托盤，讓上方拉絲酒紅立體厚鈕（浮起）與下方極深黑紅凹槽輸入框（凹陷）形成「凸／平／凹」三層鮮明對比，且單線金框不吃內距，7 顆語音試聽鈕與限紅列按鈕皆俐落無擠壓。 |
| **淺色香檳（`.skin-light`）作為輸入框或主外觀** | **排除**。雖然反差高，但本面板包含 24 格以上數字欄與輸入框，大面積鋪設亮米金底在暗室電視上過於刺眼，且容易與底部唯一金色漸層實心「儲存」按鈕搶奪視覺重心。 |
| **預設金線（`.skin-default`）作為全頁按鈕主材質** | **排除**。規範 3.1 第 16 條提醒不同頁應挑不同主外觀避免重複預設金線，且 `.skin-default` 採用 `var(--panel) → var(--panel-2)`，在本面板鎖定亮紅底上會與背景融為一體，無法一眼分出可按按鈕。 |
| **金牌鉚釘（`.skin-plate`）／黃銅銘牌（`.skin-brass`）／金屬機台鍵（`.skin-key`）** | **排除**。三者均含鉚釘、螺絲或 LED 燈號裝飾且需額外留白（`22px`～`24px`），不適合鋪滿一般按鈕與 7 連排窄試聽鈕，亦會超出特殊外觀 1～2 處上限。 |
| **主色漸層（`.skin-tone`）／氈布（`.skin-felt`）** | **排除**。主色漸層色階與亮紅面板相近且易與危險按鈕混淆；規範 2.1 明訂氈布不可泛用於彈窗、選單與提示框。 |
| **無外框柔光（`.skin-borderless`）作為按鈕或輸入框主材質** | **排除**。無框設計在 16 格限紅雙表與密集鍵位設定上缺乏清晰邊界，不利電視遠距快速定位。 |

### 為何沒採用其他結構樣式

- **分頁不用「分段切換（`.seg-switch`）」或「資料夾式頁籤（`.tabs-folder`）」**：規範第 8 節明訂分段切換不適合頁面級分頁；資料夾式頁籤需與下方舞台底板一體銜接，為避免自創總覽不存在的大舞台底板，本次選用最純粹的**底線頁籤（`.tabs` / `.tab`）**。
- **畫面風格不用「卡片式單選（`.rcard-group`）」**：規範第 5 節指出卡片式單選適合「要附說明的互斥選項」，本面板四個風格僅為單行名稱與色票，故採**按鈕式單選（`.rbtn-group` / `.rbtn-item`）**。
- **文字輸入框不用「只有底線的輸入框（`.field-underline`）」**：規範第 2 節明訂該樣式不適合「需明確邊界的表單」，故採有清楚內凹框界的**基本輸入框（`.field`）**。
- **限紅表不用「隔行換色表格（`.table.zebra`）」**：規範第 15 節明訂不適合少於五列之表格，本面板左右各 4 列，故採**金頭資料表（`.table`）**。
- **小標題不用「收合標題列（`.collapse-btn`）」**：三個分頁內容需常駐一目了然以便快速校對，故採**中間裝飾分隔線（`.div-line-wrap`）**而非手風琴收合。

## 三、特殊外觀位置與整頁統一統計

### 特殊外觀（搶眼外觀）使用位置（共 1 處，符合上限 1～2 處）

1. **對話框外框對角 17px 亮金角飾（`.dialog::before` / `::after`）**：僅用於 `#tvSettings` 整座設定視窗的左上與右下對角，作為全頁唯一焦點框飾；其餘所有按鈕、卡片、輸入框與分頁均無燈泡、金錠、螺絲、鉚釘、鑽石角、霓虹或角標。

### 整頁統一統計（規範第 5 節第 7 條）

- **材質總數**：**3 種**（上限 3 種）—— 組裝式 `.kit`（`.fill-wine.tex-brushed.light-thick.frame-single.corner-none`）、半透明毛玻璃（`.skin-glass`）、金色漸層實心（`.skin-gold`）。
