# 路單設定面板・Grok2 選用表

## 選材說明

這份替換樣式要和已有方案分開：原版／Codex 是雕刻金線，Grok／Gemini 是青銅漸層，Codex2 是皮革扶手。面板底維持現在的紅（`--panel` `#a5171a` → `--panel-2` `#7a0f12`）。尺寸與內距不改，所以主外觀不能帶額外內距、鉚釘、螺絲或內縮第二圈線。

| 主外觀候選（規範名稱） | 適合或不適合本面板的原因 |
| --- | --- |
| 雕刻金線＋方形 | 適合莊重確認與雙線內框。原版與 Codex 已用。內縮金線在 56px 鍵位框上會貼近文字。 |
| 青銅漸層＋方形 | 適合常用操作與工具列。Grok 與 Gemini 已用。 |
| 皮革扶手＋方形 | 適合貴賓座次與車縫皮標。Codex2 已用。車縫虛線與左右內距不適合密集窄欄，且隨主色變時會和紅面板黏在一起。 |
| 半透明毛玻璃＋方形 | 適合光暈上的懸浮層。這頁底是實色紅，半透明黑疊上去會發濁，多顆控制項的模糊也分不出可點與可填。 |
| 淺色香檳＋方形 | 適合高反差重點輸入。整頁鋪亮底會壓過唯一的金色儲存，電視上過亮。 |
| 無外框柔光＋方形 | 適合低干擾次級面板。密集鍵位與限紅欄沒有金框就分不出邊界。 |
| 金牌鉚釘、黃銅銘牌、金屬機台鍵 | 鉚釘、頂部金條、左右螺絲或燈號會改盒模型，窄欄放不下；螺絲與鉚釘也不能鋪滿整頁。 |
| 氈布＋方形 | 規範寫明不可泛用到彈窗、選單、提示框。 |
| 組裝式：純黑＋拉絲＋頂部高光＋單線＋無邊角，再加方形 | 純黑和紅面板分開，拉絲與頂部高光是金屬件，單線金框不吃內距。邊角不加鉚釘、燈泡、鑽石。窄鍵位、百萬數字欄、七顆試聽鈕都維持原盒。 |

**選用：組裝式一組（`.kit.fill-black.tex-brushed.light-gloss.frame-single.corner-none`）為主外觀、方形為主形狀；金色漸層實心只給選中的畫面風格與底部唯一「儲存」。** 開關與滑桿軌道用膠囊，標題列圖示鈕與色票用正圓（正圓圖示鈕不計入形狀上限）。主色 9 變數與 `--txt`、`--txt-dim` 維持現值。HTML 不能改，所以 class 寫進 `#tvSettings` 的覆蓋規則，數值照總覽抄。

依據規範原句：「先為整頁定一套『主外觀』＝1 種主材質（或 1 組 `.kit` 組合）＋1 種主形狀，頁上大多數按鈕、面板、標籤都用它；另外最多再挑 1 種輔助材質給面板或次要區塊。」「同一頁總共用的材質不超過 3 種、形狀不超過 2 種（正圓圖示鈕不計）。」「同一排、同一組的元件不得混用不同材質或形狀；層級只用『主要／次要／危險』的實心、線框、顏色差異做出來，不靠換材質。」「多樣性看頁與頁之間：不同網頁要挑不同的主外觀，避免每頁都是預設金線。」「近黑金屬面板是操作區；深綠氈布只給主要內容區與『氈布款』元件，不可泛用到彈窗、選單、提示框。」

## 角色｜元件結構｜外觀材質｜形狀｜理由

| 角色 | 元件結構 | 外觀材質 | 形狀 | 理由 |
| --- | --- | --- | --- | --- |
| 標題列 | 對話彈窗與抽屜 | 組裝式這一組不鋪在底板；標題字依 2.3 | 方形 | 彈窗底板用鎖定的紅。標題用品牌字級與金色直向漸層字。 |
| 圓形圖示鈕 | 圓形圖示按鈕 | 純黑＋拉絲＋頂部高光＋單線＋無邊角 | 正圓 | ⛶ 與 × 同組、同材質；正圓且不改現有寬高。 |
| 分頁 | 底線頁籤 | 無填色，選中金色底線 | 方形 | 頁面級三個分頁。目錄寫底線頁籤適合一般頁面切換；分段切換不適合頁面級分頁。 |
| 畫面風格單選 | 按鈕式單選 | 未選＝這一組 kit；選中＝金色漸層實心 | 方形 | 四個互斥模式。層級用實心／未選填色，不換材質。已改直角。 |
| 數字輸入 | 數字框 | 純黑＋拉絲＋頂部高光＋單線＋無邊角 | 方形 | 與按鈕同一組 kit，數字用 `--disp`。已改直角。 |
| 文字輸入 | 基本輸入框 | 純黑＋拉絲＋頂部高光＋單線＋無邊角 | 方形 | 路徑、清盤提示、限紅版本名與數字框同款，同一排才不會混材質。已改直角。 |
| 唯讀鍵位框 | 唯讀專用明顯樣式 | 結構自帶暗金虛線＋斜紋 | 方形 | 系統鎖定鍵位。目錄寫適合系統鎖定值，不得當可編輯欄。已改直角。 |
| 開關 | 勾選、單選與金色開關 | 關＝這一組純黑；開＝金色滑軌 | 膠囊（滑塊正圓） | 複製 `.rule-control` 的軌道與滑塊，不改現有寬高。已改膠囊。 |
| 滑桿 | 單軸滑桿 | 純黑軌道、金色滑塊 | 膠囊軌道、正圓滑塊 | 音量單值。目錄寫單軸滑桿適合單值調整。軌道已改膠囊。 |
| 下拉選單 | 自訂下拉選單 | 觸發鈕＝這一組 kit；清單＝紅面板 | 方形 | 限紅版本單選，取代原生選單。已改直角。 |
| 一般按鈕 | 基本按鈕 | 純黑＋拉絲＋頂部高光＋單線＋無邊角 | 方形 | 新增、限紅列儲存、選擇資料夾、試聽。全頁同一款。 |
| 主要儲存 | 基本按鈕 | 金色漸層實心 | 方形 | 底部唯一送出。規範：主要操作金色實心，同一視覺區塊最多一顆。 |
| 取消／恢復預設 | 基本按鈕 | 同一結構的幽靈線框 | 方形 | 低干擾操作。透明底與暗金框，不另加材質。 |
| 刪除 | 紅色危險按鈕 | 輕＝危險色線框（底仍是這一組 kit）；確認＝危險色實心 | 方形 | 兩段確認。先輕後重，符合 danger／danger-solid。 |
| 限紅表 | 金頭資料表 | 金色表頭字、底線分隔 | 方形 | 一般資料表。少於五列，不用隔行換色。不改格距。 |
| 小標題 | 金色標籤 | 金色字＋底線（不鋪 kit 底，避免加高） | 方形 | 分組標題常駐可見，不用收合標題列。只改字色與底線，不加標籤內距。 |
| 狀態訊息 | 帶圖示與左邊色條通知 | 純黑＋拉絲＋頂部高光＋單線＋左金條 | 方形 | 規範：狀態不用裸文字。左 4px 金條；底用 kit，才不會融進紅面板。 |

特殊外觀只用在 1 處：對話框外框的角飾彈窗（對角 17px 金角）。燈泡、金錠、撲克角標、螺絲、鑽石角、霓虹、緞帶、燕尾都沒用。

不採用資料夾式頁籤，因為那是與面板一體的內容區，不是獨立切換列。不採用數碼管，因為這裡是可編輯輸入。不採用籌碼鈕，因為不是下注面額。不採用卡片式單選，因為畫面風格沒有說明文字、必須維持單行高度。

材質 2 種（這一組 kit、金色漸層實心）。形狀 2 種（方形、膠囊；正圓不計）。特殊外觀 1 處。
