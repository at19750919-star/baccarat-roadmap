# 路單設定面板・Grok7 選用表

對應樣式：`_面板比較\設定面板-Grok7.css`（可整份替換 `tv-settings-casino.css`）。結構改在 `tv-比較-Grok7.html` 的設定對話框：既有元素加上總覽 class，並在 `tv-settings-compact.js` 後面加一段腳本，把同一組 class 補到後注入的桌號、靴號、限紅與下拉。原有 id 與 `name` 保留。

## 設計說明

底板維持已定案亮紅 `#a5171a` → `#7a0f12`。對話框用總覽 `.dialog` 的 17px 對角，邊角燈泡刻在既有 20px 內距裡。小標題整組是黃銅銘牌加螺絲。頁首兩顆圖示鈕整組是霓虹圓燈。一般按鈕整組是金屬機台鍵（青燈、4px 厚度）。底部唯一儲存整組是燈泡跑馬燈。畫面風格整組是燕尾，未選酒紅、選中金色實心。數字是黑底細直條凹陷雙線，文字是香檳凹陷內縮，唯讀是虛線斜紋。下拉是青銅拉絲平面單線。框層次、邊角裝飾、形狀都有用到。標準尺寸仍由頁面腳本設成 800×900。總覽自帶的外距、加高內距與第二個下拉箭頭沒有帶進來。

不採用先前各版用過的雕刻金、皮革、整頁香檳、拉絲高光當唯一材質、點陣、斜紋加 L 角、條紋、鉚釘當主按鈕、寶石角、霓虹當對話框框、放射紋、氈布、菱格、細直條鋪滿整頁、玻璃、銘牌當按鈕、無框、金錠、八角形、緞帶、資料夾頁籤、膠囊頁籤。氈布和主色調在這塊紅底上會黏在一起。玻璃在實心紅上會糊。銘牌和機台鍵的總覽內距會加高，所以銘牌只留水平留白，試聽列的燈縮小。燈泡和霓虹的外距拿掉，800×900 才不會捲動。錯位雙框有外距。數碼管不適合可編輯數字。籌碼不是下注面額。卡片式單選放不進單行風格。再加一層分組卡片會冒出垂直捲軸。底線欄不適合有邊界的輸入。黃銅標題不再疊分隔線，螺絲已經佔了偽元素。

## 驗證

`看面板.py` 以本機 Chrome（Playwright `channel=chrome`，視窗 1920×1080）開 `tv-比較-Grok7.html`，把 `tv-settings-casino.css` 換成這份檔。基本、按鍵、儲存都是 800×900，內容區 `scrollHeight` 與 `clientHeight` 都是 658，沒有垂直捲軸，`errors` 為空。非零圓角只有 `50%` 與 `999px`。字型堆疊是 `"Noto Serif TC", Cinzel, serif`、`Cinzel, "Noto Serif TC", serif`，基本頁另有 `"Noto Serif TC", serif`，都是 serif 結尾。截圖：`_面板比較\設定面板-Grok7-Basic.png`、`設定面板-Grok7-Keys.png`、`設定面板-Grok7-Save.png`。

量到的外觀：標題是 Cinzel 漸層字。面板紅色在 `linear-gradient(160deg, …)`。作用中分頁底線 2px、`rgb(217, 181, 104)`。燕尾 `clip-path` 在。選中的紅金風格是金漸層。數字框是細直條加黑漸層、金字、圓角 0。桌號是香檳漸層。唯讀「77」是虛線斜紋、陰影 none。關閉鈕 32×32、圓角 50%。樣式寫的霓虹外圈是 1.5px，Chrome used value 是 1px，`outline-offset` 有套上。底部儲存背景含 `radial-gradient`（燈泡），字色 `rgb(244, 223, 164)`。取消背景透明、陰影 none。新增鈕懸停 `translateY(-2px)`。下拉打開後面板圓角 0、紅漸層，項目陰影 none、左邊 2px。把清盤自動存設成未勾後，關軌是 `linear-gradient(rgb(46, 4, 5), rgb(42, 6, 7))`，圓角 999px，尺寸 50×28。試聽七顆的 `scrollWidth` 都等於 `clientWidth`，「4張超級7」沒有裁字。限紅標題「限紅」寬 94、`scrollWidth` 等於 `clientWidth`。版本列同一行（top 都是 582）。把刪除改成「確定刪除」並加上 `.is-confirm` 後仍是一行，內容區仍是 658／658，按鈕寬 101，塗色 `-webkit-text-fill-color` 為 `rgb(255, 245, 243)`，底是 `#e0483e` 起頭的紅漸層。鍵盤 Tab 時，尺寸鈕、關閉、分頁、風格鈕、桌號、靴號開關、數字框都是 `:focus-visible`，外框 `2px solid rgb(244, 223, 164)`、offset 3px。`prefers-reduced-motion: reduce` 下新增鈕 `transitionDuration` 為 `0s`。表單 `columns`、`tableNo`、`shoeNo`、`keyB`、`customSavePath`、`autoCommit`、`soundVolume` 仍對到原來的 id。後注入欄位有套上對應 class。顯示靴號預設關，靴號欄 `disabled`、透明度 0.38。
