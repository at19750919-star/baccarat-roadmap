# 路單設定面板・Grok6 選用表

對應樣式：`_面板比較\設定面板-Grok6.css`（可整份替換 `tv-settings-casino.css`）。HTML 不改，總覽 class 寫進 `#tvSettings` 的覆蓋規則。

## 設計說明

底板維持已定案亮紅 `#a5171a` → `#7a0f12`。對話框用霓虹雙管框，左右各一條金線。可按的鈕是黑底放射紋、四角鉚釘、底下有 4px 厚度；數字是深紅雙線凹陷；文字是黑底內縮金線；唯讀是虛線斜紋、沒有陰影。畫面風格未選走酒紅霓虹，選中與底部唯一儲存走金色實心。框層次、邊角裝飾、形狀都有用到。尺寸與內距不改。標準尺寸由頁面腳本設成 800×900。

## 為何沒採用其他樣式

雕刻金線、青銅漸層、皮革扶手、淺色香檳、拉絲加高光、點陣浮起、斜紋加 L 角、上下金條、內縮底線文字、絨點雙色數字框、鑽石角，前面的比較版已各用過。金錠、八角金邊、資料夾頁籤、玻璃、別針也已出現在其他比較稿。

霓虹材質款有 4px 外距與上下夾條，會把內容頂出可視區；霓虹只用在框層次，套對話框與整組畫面風格。鑽石角、螺絲、刻度、燈泡都要額外留白，56px 鍵位放不下。錯位框有外距。粗框若套上 44px 的輸入盒會裁掉 22px 字，所以粗框只放在 32px 正圓圖示鈕。氈布款不可用在彈窗。主色漸層用 `--state-1` → `--state-2`，會和紅底板黏在一起。半透明毛玻璃在實色紅底上會發濁。金牌、黃銅銘牌、金屬機台鍵同樣要留白。

不採用資料夾式頁籤，因為那是與面板一體的內容區。不採用數碼管，因為這裡是可編輯輸入。不採用籌碼鈕，因為不是下注面額。不採用卡片式單選，因為畫面風格必須維持單行。不採用分組卡片，因為再加一層底板會冒出垂直捲軸。

## 驗證

`看面板.py` 以本機 Chrome（Playwright `channel=chrome`，視窗 1920×1080）開 `tv.html`，把 `tv-settings-casino.css` 換成這份檔。基本、按鍵、儲存三個分頁都是 800×900，內容區 `scrollHeight` 與 `clientHeight` 都是 658，沒有垂直捲軸，`errors` 為空。非零圓角只有 `50%` 與 `999px`。字型堆疊是 `"Noto Serif TC", Cinzel, serif`、`Cinzel, "Noto Serif TC", serif`，儲存分頁另有 `"Noto Serif TC", serif`，都是 serif 結尾。

量到的外觀：標題字型是 `Cinzel, "Noto Serif TC", serif`，字距 3.92px，填色透明。面板 `background-color` 為透明，紅色在最後一層 `linear-gradient(160deg, rgb(165, 23, 26), rgb(122, 15, 18))`。作用中分頁底線 2px、`rgb(217, 181, 104)`。新增鈕含鉚釘層與 `0 4px 0 rgb(43, 29, 8)`，圓角 0；懸停當下 `translateY(-2px)`。底部儲存是金漸層、字色 `rgb(33, 25, 13)`。取消與恢復預設背景為 none、無陰影。數字框 `#tvBigColumns` 為 64×44、Cinzel 700、深紅漸層、雙線 outline。限紅「1,500,000」與試聽鈕文字的 `scrollWidth` 等於 `clientWidth`。唯讀鍵是虛線斜紋、陰影 none。可改鍵與桌號、靴號、路徑是黑底內縮，不是虛線。關閉與尺寸鈕 32×32、圓角 50%、3px 金框。開關開軌為 `linear-gradient(90deg, #735827, #d9b568)`；把 `#tvAutoSaveOnClear` 設成未勾後，關軌是 `linear-gradient(rgb(46, 4, 5), rgb(42, 6, 7))`，圓角 999px，尺寸仍 50×28。音量軌高 7px、圓角 999px。下拉觸發鈕是深紅凹陷、圓角 0；點開後清單是紅面板、圓角 0，選中項背景 `#d9b56814`、左邊 2px、陰影 none。按下 Esc 後面板關閉，這是頁面原有行為。

樣式表的霓虹框線寫 1.5px。Chrome 的 used value 是 1px，顏色 `#fff3cf` 與 `outline-offset: 3px` 有套上。對話框外圈光在元素盒之外，對話框截圖會裁掉外圈；內光與左右金線在截圖裡。截圖當下 `#tvAutoSaveOnClear` 是已存的開啟狀態。
