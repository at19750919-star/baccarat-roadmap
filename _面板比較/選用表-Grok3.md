# 路單設定面板・Grok3 選用表

## 設計說明

這份只替換 `tv-settings-casino.css`。面板底維持 `#a5171a` → `#7a0f12`，標準尺寸仍由頁面腳本設成 720×887，三個分頁不加高、不加內距，避免垂直捲軸。HTML 不改，所以總覽 class 寫進 `#tvSettings` 的覆蓋規則，宣告從總覽抄。

已定案要守的還有：三分頁小標題同一款（金字、20px、字距 .14em、細金底線）；固定按鍵框與一般按鍵框同款，只把字改淡，不用斜紋虛線唯讀樣式。

| 主外觀候選（規範名稱） | 適合或不適合本面板的原因 |
| --- | --- |
| 雕刻金線＋方形 | 適合莊重確認。原版與 Codex 已用，也是目前正式面板。再做一次分不出這份比較檔。 |
| 青銅漸層＋方形 | 適合常用操作。Grok、Gemini 已用。 |
| 皮革扶手＋方形 | 適合貴賓座。Codex2 已用。車縫與左右內距塞不進 56px 鍵位。 |
| 組裝式純黑拉絲／深色菱格／細直條／酒紅立體鍵 | Grok2、Gemini2、Gemini3、Gemini4、Gemini5 已各用一組。再挑黑底或酒紅會和它們貼在一起。 |
| 金牌鉚釘、黃銅銘牌、金屬機台鍵＋方形 | 頂部金條、左右螺絲或燈號要額外留白，窄鍵位與七顆試聽鈕放不下。鉚釘、螺絲也不能鋪滿整頁。 |
| 氈布＋方形 | 規範寫明不可泛用到彈窗、選單、提示框。 |
| 半透明毛玻璃＋方形 | 實色紅底上會發濁。Gemini5 已拿它當輔助卡片。 |
| 八角金邊、燈泡跑馬燈 | 規範限定每頁最多一兩處，不能當整頁主外觀。 |
| 淺色香檳＋方形 | 象牙底、深褐字、1px 金框，不另加內距。紅面板上和前面的深色金屬方案一眼分開。字維持深色，不跟唯一的金色儲存變成同一種亮金。 |

**選用：淺色香檳（`.skin-light`）為主材質、方形為主形狀；金色漸層實心（`.skin-gold`）只給選中的畫面風格與底部唯一「儲存」。** 開關與滑桿軌道用膠囊，頁首圖示鈕與色票用正圓（正圓不計入形狀上限）。

依據規範原句：「先為整頁定一套『主外觀』＝1 種主材質（或 1 組 `.kit` 組合）＋1 種主形狀，頁上大多數按鈕、面板、標籤都用它；另外最多再挑 1 種輔助材質給面板或次要區塊。」「同一頁總共用的材質不超過 3 種、形狀不超過 2 種（正圓圖示鈕不計）。」「同一排、同一組的元件不得混用不同材質或形狀；層級只用『主要／次要／危險』的實心、線框、顏色差異做出來，不靠換材質。」「不同網頁要挑不同的主外觀，避免每頁都是預設金線。」「近黑金屬面板是操作區；深綠氈布只給主要內容區與『氈布款』元件，不可泛用到彈窗、選單、提示框。」

特殊外觀只用在 1 處：對話框對角 17px 金角（`.dialog::before`／`::after`）。燈泡、金錠、撲克角標、螺絲、鑽石角、霓虹、緞帶、燕尾都沒用。

不採用資料夾式頁籤，因為那是與面板一體的內容區，不是獨立切換列。不採用數碼管，因為這裡是可編輯輸入。不採用籌碼鈕，因為不是下注面額。不採用卡片式單選，因為畫面風格沒有說明文字、必須維持單行高度。不採用唯讀專用明顯樣式，因為已定案取消斜紋虛線。

材質 2 種（淺色香檳、金色漸層實心）。形狀 2 種（方形、膠囊；正圓不計）。特殊外觀 1 處。開關與滑桿的深軌、金滑塊是該結構自己的顏色，沒有再加第三種 `.skin-*`。DOM 沒有這些 class，因為 HTML 不能改；材質是用同一組宣告覆蓋上去。

淺色香檳的 hover 用總覽 `button.skin-light:hover`（亮度 1.04、金框、上移 1px），不把字改成金色，否則象牙底上金字看不清。按下用 `.tool-btn:active` 的 `scale(.97)`。聚焦外框用 `outline: 2px solid var(--gold-1)`。
